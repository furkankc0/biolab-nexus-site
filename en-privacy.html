Privacy

In short: this site collects no data about you. The records in the program belong to your institution and are never sent to the developer.

This website

  • It uses no cookies, contains no visitor counter or tracking code, and asks for no information through forms.
  • All files, including the fonts, are loaded from this site itself; no request is sent to any other site.
  • The site is hosted on GitHub Pages and the download files are served from GitHub. GitHub may record technical information such as visitors’ IP addresses in order to provide the service and keep it secure; details are in GitHub’s privacy statement.
  • If you email us, we use your address and your message only to reply to you.

The program

  • The institution that uses the program is the data controller for the records and personal data entered into it (names, email addresses, usernames, the audit log). The institution prepares the privacy notice for its staff and students.
  • When the program runs on our server, we act as data processor on the institution’s behalf; this is governed by an agreement with the institution. Each institution’s data is kept separate.
  • The program never sends institutional data to the developer. A licence request contains only digests derived from the computer’s hardware details; it contains no serial numbers and no personal data.
  • Passwords are stored in a form that cannot be reversed and are never sent by email.
