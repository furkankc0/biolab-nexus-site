Download HMZ Lab

Latest version 0.89.0, 19 November 2026. Download files only from this page; an installer obtained elsewhere may have been altered. The program’s interface is available in English and Turkish.

Windows

Coming soon

The Windows installer is ready and being tested. The download link will appear here once the signed release is published; for pilot institutions we currently do the installation ourselves.

  • Windows 10 or 11, 64-bit
  • At least 4 GB of memory and 2 GB of free disk space
  • No need to install Python or any other program; no administrator permission is asked for
  • The 16S reference and BLAST are downloaded once from inside the program on first use (about 150 MB; internet needed)

  • Your institution’s HMZ Lab address (ask your administrator)
  • On first install you need to allow installs from this source; how?

iPhone and iPad

Nothing is downloaded on an iPhone; the program is added to the home screen from Safari and opens full screen with its own icon.

  1. Open your institution’s HMZ Lab address in Safari.
  2. Tap the Share button.
  3. Choose Add to Home Screen, then Add.
  4. Open the program from the HMZ Lab icon on the home screen.
  • iOS or iPadOS 16.4 or later recommended
  • Your institution’s HMZ Lab address

Verify the file you downloaded

Every file has a SHA-256 verification code. If the code calculated on your computer is exactly the same as the one below, the file is the one we published.

Verification codes will appear here once the installers are published.

Windows: open PowerShell in the folder that holds the file and type:

Get-FileHash .\FILE_NAME -Algorithm SHA256

macOS and Linux:

shasum -a 256 FILE_NAME

What’s new in this version

  • The program has a new name: HMZ Lab (formerly BioLab Nexus). Installing over the old version moves your records automatically.
  • Windows installer: no Python needed and no administrator permission asked for; the program opens in its own window and stops by itself when the window is closed. Records are kept in a separate folder that updates and uninstalling never delete.
  • Account security: the number of sessions open at the same time on one account is limited (2 by default; the administrator can choose 1–5). Signing in on another device closes the oldest session, and that device is told why. You can see and close your open sessions in Settings.
  • The program can now be used in English: choose it in the Language box in the top bar (on a phone, at the bottom of the Menu); your records are not translated.
  • The website is in English and Turkish, with English screenshots of the program on the English pages.
  • Account requests and approval: the invitation goes to the school email address, and people choose their own username.
